# יומן

אפליקציית לו״ז אישית: שבוע קבוע שחוזר, ושינויים לימים מסוימים.

- **המסך הראשי** – יומן עם תאריכים. לחיצה על פעילות משנה אותה **ליום הזה בלבד**. כפתורי ״היום״ / ״מחר״ למעלה, החלקה ימינה/שמאלה בין ימים, ולחיצה על שם החודש פותחת לוח חודשי.
- **הלו״ז הקבוע** – בתפריט (☰). שינוי שם חל על כל השבועות.
- **גיבוי ושחזור** – בתפריט. הלו״ז נשמר רק בדפדפן במכשיר (localStorage), **לא בקוד**. שומרים קובץ גיבוי (`yoman-backup-….json`) וטוענים אותו במכשיר חדש.

## הרצה

אין בנייה ואין תלויות. אלה קבצים סטטיים:

- `index.html` – כל האפליקציה
- `manifest.webmanifest`, `sw.js`, `icons/` – כדי שאפשר יהיה להתקין אותה למסך הבית ושתיפתח גם בלי רשת

לפרסום ב-GitHub Pages: ‏Settings ← Pages ← Deploy from a branch ← `main` / `root`.
להרצה מקומית: `npx serve .` ופותחים את הכתובת שמודפסת.

## מבנה קובץ הגיבוי

```json
{
  "app": "yoman",
  "version": 1,
  "categories": [ {"id":"study","name":"לימוד","color":"blue","track":true} ],
  "week": [
    { "day": "ראשון", "subtitle": "…", "accent": "study",
      "items": [ {"start":"09:00","end":"11:00","title":"…","note":"…","cat":"study"} ] }
  ],
  "days": {
    "2026-10-14": { "items": [ … ] }
  },
  "notes": ""
}
```

- `week` – שבעה ימים, מראשון עד שבת. זה הלו״ז הקבוע.
- `days` – שינויים לתאריך מסוים. יום שמופיע כאן מחליף את הלו״ז הקבוע של אותו תאריך.
- פעילות בלי `end` נמשכת עד הפעילות הבאה (למשל שינה עד הקימה של מחר).
- פעילות בלי `start` מקבלת `when` – זמן במילים, כמו ״עד צאת שבת״.
- צבעים אפשריים: `amber`, `orange`, `red`, `pink`, `violet`, `blue`, `cyan`, `teal`, `green`, `brown`, `slate`, `gray`.
